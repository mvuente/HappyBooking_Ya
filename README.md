# HappyBooking_Ya
Проект HappyBooking_Ya выполнен на .Net 10.
Для получения проекта из публичного репозитория необходимо выполнить git clone mvuente/HappyBooking_Ya
Использованные в проекте зависимости можно восстановить dotnet restore
Собирается проект dotnet build
Запускается проект dotnet run
Схему api проекта можно увидеть в swagger http://localhost:<yourPort>/swagger; номер порта можно увидеть в выводе в терминале при запуске проекта
Хранение событий организовано в виде списка
При удалении события из списка его id возможен к дальнейшему использованию. При создании нового события алгоритм сначала пытается использовать ранее высвобожденные id.
Запрос GET/events можно выполнять с фильтрацией: title - фрагмент заголовка события (null по умолчанию, тогда параметр не применяется); from - нижняя граница даты начала события ((null по умолчанию, тогда параметр не применяется); to - верхняя граница даты окончания события (null по умолчанию, тогда параметр не применяется). Параметры пагинации: page - номер страницы вывода (1 по умолчанию); pageSize - размер страницы вывода (10 по умолчанию).
Пример запроса: curl "http://localhost:<yourPort>/api/events?title=<вашЗаголовок>&from=<датаНачала yyyy-MM-dd>&to=<датаОкончания yyyy-MM-dd>&page=<номерСтраницы>&pageSize=<размерСтраницы>"
Пример успешного ответа:
StatusCode: 200
StatusDescription: OK
Content: {"data":"totalEventsNumber":<количествоСобытийвВыборке>,
	"events":[{"id":<id>,
		"title":<title>,
		"description":<description>,
		"startAt":<startAt>,
		"endAt":<endAt>}],
	"page":<номерСтраницы>,
	"pageSize":<размерСтраницы>,
},
"success": true,
 "statusCode": 200,
 "message": "Получаем события из коллекции в соответствии с параметрами запроса"

К проекту подготовлены юнит тесты (восстановите зависимости). Тесты запускаются dotnet test
